## Hypotheses, not confirmed defects

Excessive session bias, plural stemming quality, and hybrid/lexical benchmark gains need controlled datasets and explicit configuration. No LOCOMO ranking regression is inferred from the historical numbers. SQLite FTS5/BM25 may reduce scan cost; no measured candidate coverage or recall comparison currently justifies replacing the ranking system. No severity is inflated for these hypotheses.

There are no known external-repository changes, new runtime dependencies, network calls in Core, or new retrieval algorithms in this work. Open blocker tests are strict xfails, not counted as passing validations.
